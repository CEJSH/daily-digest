

## 📰 뉴스 큐레이팅 MVP - 최종 구현 계획

> **"아무것도 하기 싫은 날, 3분 만에 하루를 정리해주는 뉴스"**

---

### 🎯 핵심 목표
- 하루 5개의 엄선된 뉴스로 "정리된 느낌" 제공
- 뉴스페이퍼 스타일의 클래식하고 신뢰감 있는 디자인
- 반응형 레이아웃 (모바일 + 데스크톱)
- 수동 입력 기반으로 빠른 운영 시작
- **신뢰도 장치 강화** (업데이트 시각, 편집자 주)

---

### 📱 화면 구성

#### 1. 메인 페이지 (뉴스 피드)

**헤더 영역**
- 서비스 로고/제목: "오늘, 이 정도만 알면 충분합니다"
- 오늘 날짜 표시
- ✨ **업데이트 시각 표시** (예: `업데이트: 2026.02.02 오전 7:30`)
- 뉴스페이퍼 느낌의 타이포그래피

**선정 기준 섹션**
- 토글 형태로 펼치기/접기 가능
- 3가지 선정 기준 안내:
  - 내일도 영향이 남는 이슈
  - 과도한 감정 소모 제외
  - 어제와 중복되는 뉴스 제외

**✨ 편집자 주 (서비스 정체성)**
- 선정 기준 바로 아래 배치
- 고정 문구: *"이 뉴스는 클릭 수가 아니라 오늘 이후에도 남는 정보만 기준으로 편집했습니다."*

**뉴스 카드 (5개 고정)**
- 카테고리 태그 (IT / 경제 / 글로벌)
- ✨ **읽는 시간 표시** (예: ⏱ 20초) - 요약 길이 기반 계산
- 편집된 제목
- 3줄 요약
- "왜 중요한가" 1줄
- 원문 보기 링크 (접기/펼치기)

**오늘의 질문 섹션**
- 뉴스와 연결된 생각 질문 1개
- 읽기 전용 (입력 없음)

**✨ Empty/Error State (뉴스 없을 때)**
- 부드러운 안내 메시지: *"오늘은 쉬어가는 날입니다. 내일 아침에 다시 정리해드릴게요."*
- 운영 지연/실수에 대비한 우아한 처리

**푸터 영역**
- 서비스 철학 메시지
- ✨ **아카이브 링크** (작게): "지난 뉴스 보기 →" (SEO/미래 자산용)
- 광고 영역 (AdSense 1개 배치 자리)

---

### 🎨 디자인 방향

**뉴스페이퍼 스타일**
- 세리프 폰트 활용 (제목)
- 깔끔한 그리드 레이아웃
- 흑백 톤 기반 + 카테고리별 포인트 컬러
- 적절한 여백과 구분선
- 클래식한 타이포그래피 계층

**반응형**
- 데스크톱: 중앙 정렬, 최대 너비 제한 (신문 느낌)
- 모바일: 카드형 세로 스크롤

---

### 💾 데이터 구조 (미래 대비 포함)

**뉴스 데이터**
```
- id: 고유 식별자
- date: 발행 날짜
- category: IT | 경제 | 글로벌
- title: 편집된 제목
- summary: 3줄 요약 (배열)
- whyImportant: 중요한 이유 1줄
- sourceUrl: 원문 URL
- ✨ status: draft | published (운영/자동화 대비)
- ✨ importance: 1 | 2 | 3 (우선순위, 화면 미노출)
```

**오늘의 질문 데이터**
```
- date: 날짜
- question: 질문 내용
```

**메타 데이터**
```
- lastUpdatedAt: 최종 업데이트 시각
```

### 🔧 기술 구현

**프론트엔드**
- React + TypeScript
- 샘플 뉴스 데이터로 시작 (추후 Supabase DB 연동 가능)
- 반응형 레이아웃

**✨ SEO 최소 대비 (주석/문서화)**
- `<title>`: `오늘의 핵심 뉴스 5개 | YYYY.MM.DD`
- `<meta description>`: `3분 만에 하루를 정리하는 뉴스 요약`
- Open Graph 태그 기본 설정

**읽는 시간 계산 로직**
- 요약 텍스트 글자 수 기반
- 한국어 평균 읽기 속도 (~500자/분) 적용
- 10초 단위 반올림 표시

### 📋 구현 순서

1. **메인 레이아웃** - 뉴스페이퍼 스타일 기본 구조
2. **헤더** - 날짜 + 업데이트 시각 표시
3. **선정 기준 토글** + 편집자 주 문구
4. **뉴스 카드 컴포넌트** - 카테고리, 읽는 시간, 요약, 중요도
5. **오늘의 질문** - 하단 배치
6. **Empty/Error State** - 뉴스 없을 때 처리
7. **푸터** - 철학 메시지 + 아카이브 링크 + 광고 영역
8. **샘플 데이터** - 실제 운영 형태 시뮬레이션
9. **SEO 메타 태그** - title, description 설정
10. **반응형 최적화** - 모바일/데스크톱 확인
